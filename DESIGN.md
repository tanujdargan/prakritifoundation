# Prakriti Foundation — Design System

Single source of truth for the visual redesign. Every component must conform.
If a rule here conflicts with what a file currently does, **this file wins**.

---

## Why this exists

The site was generated by Bolt.new and carries every visual tell of AI-default
output: blue→green gradients on section headers and CTAs, `hover:scale-105` on
literally every card, uniform `rounded-xl shadow-lg` on every surface, and
unrelated stock photos. It reads as templated, which for a charity asking
strangers for money is a credibility problem, not just an aesthetic one.

**The anchor is the foundation's own letterhead.** Their 80G donation receipt is
deep forest green on cream paper, with botanical leaf motifs, a paw mark, and
"For a kinder world" set in script. That is a real identity, and the website
currently ignores it completely. We are making the site match the document
donors actually receive.

We are *not* adopting the generic "compassion blue + action orange" charity
palette. Trading one generic blue for another is lateral movement.

## Colour tokens

Defined once in `tailwind.config.js` under `theme.extend.colors.pf`, and used
via Tailwind classes (`bg-pf-cream`, `text-pf-forest`). **Never write a raw hex
in a component.**

| Token | Hex | Role |
|---|---|---|
| `pf-forest` | `#1B4332` | Primary. Headings, dark bands, primary buttons. |
| `pf-moss` | `#2D6A4F` | Secondary green. Icons, accents, hover states. |
| `pf-sage` | `#E8EFE7` | Pale green wash for alternating section bands. |
| `pf-cream` | `#FAF7F0` | Page background — the letterhead paper colour. |
| `pf-ink` | `#1C1917` | Body text. |
| `pf-muted` | `#57534E` | Secondary/supporting text. |
| `pf-border` | `#E3DDD0` | Hairlines, card borders, dividers. |
| `pf-marigold` | `#9A3412` | Accent / primary CTA. Warm, Indian, deliberately not the default AI orange. |

### Verified contrast (all pass WCAG AA)

| Pair | Ratio |
|---|---|
| `pf-forest` on `pf-cream` | 10.35:1 |
| `pf-ink` on `pf-cream` | 16.35:1 |
| `pf-muted` on `pf-cream` | 7.13:1 |
| `pf-marigold` on `pf-cream` | 6.83:1 |
| `pf-cream` on `pf-forest` | 10.35:1 |
| white on `pf-marigold` | 7.31:1 |
| white on `pf-forest` | 11.08:1 |
| `pf-moss` on `pf-cream` | 5.97:1 |

Any **new** pair you introduce must be checked, not assumed. `pf-muted` is the
lightest text permitted on cream — do not go lighter.

## Typography

Load via one `<link>` in `index.html` with `display=swap`.

- **Headings — `Newsreader`** (serif). Editorial and humane. A serif heading is
  the single fastest way to stop looking like AI default output, because the
  default is always a bold sans.
- **Body / UI — `Inter`**.

```
font-display: Newsreader, Georgia, serif
font-sans:    Inter, system-ui, sans-serif
```

Scale — use these, don't invent sizes:
`12 · 14 · 16 · 18 · 20 · 24 · 30 · 36 · 48`

- Body copy 16–18px, `leading-relaxed` (1.625).
- Headings `font-display`, weight 500–600, `leading-tight`, `tracking-tight`.
- **Never** set body text below 14px. Legal small print may use 12px.
- Measure: cap long-form paragraphs at `max-w-prose` (~65ch).

## Shape, depth, spacing

- **Radius:** cards `rounded-lg` (8px), buttons/inputs `rounded-md` (6px),
  images `rounded-md`, tags `rounded-full`. Nothing larger than `lg`.
- **Depth comes from borders, not shadows.** Default card is
  `border border-pf-border bg-white`. `shadow-sm` is the maximum permitted;
  `shadow-lg` and above are banned.
- **Spacing:** 4/8px rhythm only. Section padding `py-20` desktop / `py-14`
  mobile. Container `max-w-6xl mx-auto px-4 sm:px-6 lg:px-8`.
- Alternate section backgrounds `pf-cream` → white → `pf-sage` to create rhythm.
  Do not put every section on white.

---

## Motion

- Duration **150–250ms**, `ease-out`. Nothing over 300ms.
- **Hover never changes layout bounds.** Transition `border-color`,
  `background-color`, or `color`. Transform-based hover is banned (see below).
- At most 1–2 animated elements per viewport. No infinite/looping animation.
- Respect `prefers-reduced-motion: reduce` — wrap any non-trivial motion:
  ```css
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
      animation-duration: 0.01ms !important;
      animation-iteration-count: 1 !important;
      transition-duration: 0.01ms !important;
      scroll-behavior: auto !important;
    }
  }
  ```

## Banned — these are the AI-slop tells

Each of these currently appears in the codebase. None may survive.

| Banned | Use instead |
|---|---|
| `bg-gradient-to-r from-blue-600 to-green-600` (and every blue→green gradient) | Flat `bg-pf-forest` or `bg-pf-sage` band |
| `transform hover:scale-105` / any hover scale on cards | `hover:border-pf-moss` + `hover:bg-pf-sage/40` |
| `rounded-xl shadow-lg` on every card | `rounded-lg border border-pf-border` |
| Blue accents (`blue-600`, `blue-300`, `blue-100`…) | `pf-forest` / `pf-moss` / `pf-marigold` |
| Emoji as icons | `lucide-react` SVG, consistent stroke width |
| Raw hex in components | `pf-*` tokens |
| `text-gray-*` on coloured backgrounds without a contrast check | verified token pair |

## Semantic danger colour

The `pf-*` palette deliberately contains no red. Destructive and error states
must stay legible as *danger* rather than as brand, so they use Tailwind's
stock reds — this is the one sanctioned exception to "tokens only":

- Destructive buttons (Delete, Block): `border-red-200 text-red-800 hover:bg-red-50`
- Error banners: `bg-red-50 border-red-200 text-red-800`, with `role="alert"`

`red-800` on `red-50` is 7.60:1. Never use red as a decorative accent — only to
mark something destructive or failed, and always paired with text or an icon
so meaning never rests on colour alone.

## Accessibility (non-negotiable)

- Body text ≥ 4.5:1. Large text ≥ 3:1.
- **Visible focus rings** on every interactive element:
  `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-pf-marigold focus-visible:ring-offset-2`.
  Never `outline-none` without a replacement.
- Tap targets ≥ 44×44px. Pad small icon buttons out to size.
- `aria-label` on every icon-only button.
- Sequential headings — one `h1` per page, no skipped levels.
- Every `<img>` needs a descriptive `alt`, plus `loading="lazy"` and explicit
  `width`/`height` (or `aspect-[…]`) to prevent layout shift.
- `cursor-pointer` on everything clickable.

---

## Imagery

Stock photos stay (there is no photo library yet), but they must read as one
deliberate set rather than assorted stock:

- Uniform aspect ratio per section — `aspect-[4/3]` for cards.
- `object-cover`, and a subtle `bg-pf-forest/10` overlay so warmth is consistent.
- Never letterbox or stretch.
- The jellyfish photo previously used for "rescue" is gone; do not reintroduce
  imagery unrelated to the subject.

---

## Responsive

Breakpoints 375 / 768 / 1024 / 1440. Mobile-first. No horizontal scroll at
375px. Grids collapse `lg:grid-cols-3` → `md:grid-cols-2` → single column.
